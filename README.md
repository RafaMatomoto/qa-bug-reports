# QA Bug Reports

Repositório dedicado a estudos de caso independentes sobre Quality Assurance (QA), testes de software e investigação de aplicações web.

## Objetivo

Desenvolver habilidades práticas de identificação, análise, reprodução e documentação de inconsistências em aplicações, utilizando ferramentas de desenvolvimento e técnicas de investigação.

## Tecnologias e ferramentas

- Google Chrome DevTools
- JavaScript
- HTML e DOM
- Git e GitHub
- Documentação técnica de bugs

## Estudos de caso

| Projeto | Tipo de investigação | Status |
|---|---|---|
| Shopee Brasil | Inconsistência em elementos HTML `<title>` | Reportado |

## Metodologia

Cada estudo de caso poderá conter:

- Descrição do problema.
- Ambiente de reprodução.
- Passos para identificação.
- Resultado esperado e resultado observado.
- Evidências visuais e técnicas.
- Análise e possíveis causas.
- Status do relato.

## Sobre o projeto

Este repositório possui finalidade educacional e demonstração de habilidades técnicas desenvolvidas por meio de investigações independentes.

As análises não representam auditorias oficiais, testes autorizados ou vínculos profissionais com as empresas mencionadas.
